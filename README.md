# Personal Mini-Toolkit

A menu-driven Python program that bundles four small everyday tools in one place. It was built as the final project for the PLP Python course.

## What it does

The program shows a main menu and keeps running until you choose Quit.

1. **To-Do List** - add, view and remove tasks (stored in a list while the program runs)
2. **Simple Calculator** - add, subtract, multiply or divide two numbers
3. **Temperature Converter** - Celsius to Fahrenheit and Fahrenheit to Celsius
4. **Multiplication Table** - prints the 1 to 12 times table for any whole number
5. **Quit**

Invalid menu choices and invalid numbers get a polite message instead of crashing the program.

## How to run it

1. Install Python 3 (https://www.python.org/downloads/).
2. Clone this repository or download `toolkit.py`.
3. Open a terminal in the project folder and run:

   ```
   python toolkit.py
   ```

   (On some systems use `python3 toolkit.py`.)

## Files

- `toolkit_plan.txt` - the plan: tools, exact menu text and concepts used
- `toolkit.py` - the program
- `screenshots/` - screenshots of the menu (including an invalid choice) and each tool running
